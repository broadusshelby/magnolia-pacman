# 🌸 Magnolia Bloom Flower Chase

A floral-inspired Pac-Man style game where you guide a magnolia blossom through blooming gardens while avoiding buzzing bees.

## 🎮 How to Play
- Use arrow keys on desktop
- Use petal controls on mobile
- Collect all flowers (✿) to advance to the next level
- Avoid the bees (🐝)

## 🌼 Features
- Multiple levels
- Increasing difficulty
- Mobile + desktop controls
- Floral themed design
